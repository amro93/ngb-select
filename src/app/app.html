API Reference

Detailed list of all Input properties, Output events, and Content Templates.

Name Type Default Description
optionsany[][]An array of objects or primitives to display as selectable options.
optionLabelstring'label'Field name to resolve the displayed label string of an option.
optionValuestring'value'Field name to resolve the bound value. If undefined, whole object is used.
placeholderstringundefinedDefault placeholder text when no item is selected.
filterbooleanfalseWhen true, displays a search input field to filter items.
filterBystringundefinedComma-separated list of fields to search against (e.g. 'name,code').
filterMatchModestring'contains'Filter search strategy: contains, startsWith, endsWith, equals.
groupbooleanfalseWhether options are categorized into groups with non-selectable headers.
editablebooleanfalseWhen true, enables combobox mode allowing custom typed inputs.
showClearbooleanfalseDisplays a clear icon to quickly reset the selected value to null.
disabledbooleanfalseDisables interactions with the component.
loadingbooleanfalseDisplays a Bootstrap loading spinner.
floatLabelbooleanfalseEnables Bootstrap .form-floating styling.
invalidbooleanfalseApplies Bootstrap .is-invalid validation class.
size'small' | 'large'undefinedComponent size (.form-select-sm or .form-select-lg).
variant'filled' | 'outlined''outlined'Appearance variant (filled adds .bg-light).
dataKeystringundefinedProperty to uniquely compare object values rather than by reference.
focusOnOpennumberundefinedIndex of option to scroll & focus on popup open.
appendTostring | HTMLElementundefinedAppends overlay to 'body' to prevent container clipping.
Name Parameters Description
onChangeevent: SelectChangeEventEmitted when a new option value is chosen.
onFilterevent: SelectFilterEventEmitted when user types inside search input.
onFocusevent: FocusEventEmitted when component trigger gains focus.
onBlurevent: FocusEventEmitted when component trigger loses focus.
onShowevent: EventEmitted when the dropdown panel opens.
onHideevent: EventEmitted when the dropdown panel closes.
onClearevent: EventEmitted when the clear icon is clicked.
onLazyLoadevent: SelectLazyLoadEventEmitted when panel is scrolled near bottom for lazy loading.
overlayVisibleChangevisible: booleanEnables two-way binding on [(overlayVisible)].
Template Ref Context Variable Description

#footer-Injected at the bottom of the dropdown overlay.
#empty-Custom content when no options match the filter or list is empty.
#clearIcon-Custom icon for the clear button.
