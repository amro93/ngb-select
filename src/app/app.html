API Reference

Detailed list of all Input properties, Output events, and Content Templates.

Version: v{{ appVersion }}
Name Type Default Description
options any[] [] An array of objects or primitives to display as selectable options.
optionLabel string 'label' Field name to resolve the displayed label string of an option.
optionValue string 'value' Field name to resolve the bound value. If undefined, whole object is used.
multiple boolean false When true, enables multi-selection with checkbox controls. Model binds to an array.
display 'comma' | 'chip' 'comma' Defines display mode for multi-select: comma-separated text or removable badge chips.
showSelectAll boolean false When true, renders a "Select All" checkbox header in the overlay panel.
selectionLimit number undefined Maximum number of items the user is permitted to select.
maxSelectedLabels number 3 Threshold of selected item labels before switching to summary text.
selectedItemsLabel string '{0} items selected' Summary template displayed when selection exceeds maxSelectedLabels.
placeholder string undefined Default placeholder text when no item is selected.
filter boolean false When true, displays a search input field to filter items.
filterBy string undefined Comma-separated list of fields to search against (e.g. 'name,code').
filterMatchMode string 'contains' Filter search strategy: contains, startsWith, endsWith, equals.
group boolean false Whether options are categorized into groups with non-selectable headers.
editable boolean false When true, enables combobox mode allowing custom typed inputs.
showClear boolean false Displays a clear icon to quickly reset the selected value to null.
disabled boolean false Disables interactions with the component.
loading boolean false Displays a Bootstrap loading spinner.
floatLabel boolean false Enables floating label styling.
floatLabelVariant 'on' | 'in' | 'over' 'on' Floating label style variant: 'on' (outlined on border), 'in' (inside box), or 'over' (above field).
invalid boolean false Applies Bootstrap .is-invalid validation class.
size 'small' | 'large' undefined Component size (.form-select-sm or .form-select-lg).
variant 'filled' | 'outlined' 'outlined' Appearance variant (filled adds .bg-light).
dataKey string undefined Property to uniquely compare object values rather than by reference.
focusOnOpen number undefined Index of option to scroll & focus on popup open.
focusOnOpenStrategy 'always' | 'notSelected' 'always' Determines whether focusOnOpen applies always or only when no item is selected.
appendTo string | HTMLElement undefined Appends overlay to 'body' to prevent container clipping.
Name Parameters Description
onChange event: SelectChangeEvent Emitted when a new option value is chosen.
onFilter event: SelectFilterEvent Emitted when user types inside search input.
onFocus event: FocusEvent Emitted when component trigger gains focus.
onBlur event: FocusEvent Emitted when component trigger loses focus.
onShow event: Event Emitted when the dropdown panel opens.
onHide event: Event Emitted when the dropdown panel closes.
onClear event: Event Emitted when the clear icon is clicked.
onSelectAllChange event: SelectSelectAllChangeEvent Emitted when "Select All" checkbox is toggled.
onRemoveChip event: SelectRemoveChipEvent Emitted when a chip is removed via close button.
onLazyLoad event: SelectLazyLoadEvent Emitted when panel is scrolled near bottom for lazy loading.
overlayVisibleChange visible: boolean Enables two-way binding on [(overlayVisible)].
Template Ref Context Variable Description
#item let-option Custom template for each individual dropdown item.
#selectedItem / #label let-value Custom template for displaying the selected value / label in the trigger box.
#chip let-value Custom template for rendering chips in multi-select mode.
#headerCheckbox let-checked Custom template for rendering the "Select All" checkbox header.
#group let-group Custom template for option group headers.
#header - Injected above the search input and items list in the overlay.
#footer - Injected at the bottom of the dropdown overlay.
#empty - Custom content when no options match the filter or list is empty.
#clearIcon - Custom icon for the clear button.
#dropdownIcon - Custom icon for the dropdown caret.
#filterIcon - Custom icon for the search bar.
